Jogo interativo no estilo “escolha sua aventura” com tema da 3 guerra mundial, utilizando HTML, CSS e JavaScript. O jogador faz escolhas que determinam o rumo da história.

---
## 📚 Aprendizados
Jogo estilo "escolha sua aventura"
Fundamentos de Java script
Event Listeners, botões, funções e condicionais
Trabalho em equipe

## ⚙️ Funcionalidades
no SIMULADOR DA 3 GUERRA MUNDIAL cada "escolha" que você faz altera um final da história sendo bom ou ruim.

## 🛠️ Stack


- JavaScript
- HTML5
- CSS3

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/daviperes-st/simulador-da-3-guerra-mjndial
```

2. Abra o arquivo `index.html` em seu navegador.
